# Filesystem Scanner

A powerful command-line tool for analyzing disk usage and file system structure.

## Overview

This scanner provides detailed insights into your filesystem, including:
- Total storage consumption
- Individual file/directory sizes
- Hidden file detection
- Permission error handling
- Recursive directory exploration

## Features

**Comprehensive Scanning**
- Traverses entire directory structures
- Follows symbolic links safely
- Skips broken symlinks automatically
